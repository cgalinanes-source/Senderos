# Senderos

Mapa interactivo de trekkings en Argentina: filtros por dificultad y región, lista para hacer, progreso, niveles y desafíos.

Fuera de claude.ai el progreso se guarda en el navegador de cada visitante.

Distancias, desniveles y coordenadas son valores típicos aproximados. Verificá con cada parque antes de salir.

Mapa base: Natural Earth (dominio público), vía world-atlas.
